## SkyBlock: предметы и инвентарь

Команды `armor`, `equipments`, `inventory` и `item` Не работают! Работают толька !forge и !sacks.

```text
!armor fiokem
!eq fiokem
!inventory fiokem
!inventory fiokem 1
!item 1 fiokem
!sacks fiokem
!forge fiokem
```

Aliases:

- `!armor`, `!armors`, `!skyblockarmor`, `!skyblockarmors`
- `!eq`, `!equipments`, `!equipment`, `!equip`
- `!inventory`, `!inv`, `!hotbar`, `!renderinv`, `!renderinventory`
- `!item`, `!render`, `!slot`, `!renderslot`, `!renderitem`

## Soopy-сокращение `!-`

`!-` — это короткая форма команды Soopy. Она эквивалентна `!soopy`:

```text
!soopy rtca fiokem m7 50
!- rtca fiokem m7 50
```
